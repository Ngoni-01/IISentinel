How rogue-device detection works
A consumer router left in the wrong mode can start handing out addresses on a floor and quietly break connectivity for everyone on it. Standard tools only show the gateway you received — they cannot see the offender. Sentinel places a small sensor inside each segment that watches which devices answer address requests, and flags any that is not the sanctioned one by its exact IP and hardware address — so you can walk straight to the port and unplug it.
To activate on a segment: run the network sensor on any Linux box or Raspberry Pi on that VLAN. It reports here automatically — no inbound access required.
